01. Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create web pages and structure content on the internet.

What is HTML?

HTML tells a web browser how to organize content such as headings, paragraphs, images, links, tables and forms.

Uses of HTML

  • Creating websites and web pages.
  • Displaying text, images and videos.
  • Creating forms for collecting information.
  • Building the structure of web applications.

Basic HTML Example

<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>Welcome to HTML.</p>
</body>
</html>
HTML provides structure. CSS controls appearance, while JavaScript adds interactivity.

02. History of HTML

HTML was developed by Tim Berners-Lee around 1991 as a way to share and connect documents over the internet.

Major HTML Versions

  • HTML 1.0: The earliest version, with basic document structure and links.
  • HTML 2.0: Introduced standardized features and forms.
  • HTML 3.2: Added tables, scripting and more presentation features.
  • HTML 4.01: Improved support for stylesheets and scripting.
  • XHTML: Applied stricter XML-style syntax rules to HTML.
  • HTML5: Introduced semantic elements, audio, video and modern browser features.

Importance of HTML5

Modern HTML supports multimedia, accessible page structures, forms and features needed by modern websites.

03. HTML Document Structure

An HTML document follows a standard structure that helps browsers understand and display a web page.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>
<body>
    <h1>Welcome</h1>
    <p>This is my website.</p>
</body>
</html>

Explanation

  • DOCTYPE: Declares that the document uses HTML5.
  • html: Contains the entire HTML document.
  • head: Holds metadata and page information.
  • title: Sets the browser tab title.
  • body: Contains the visible page content.

05. HTML Attributes

Attributes provide additional information about HTML elements. They are normally written inside the opening tag.

  • style: Adds inline CSS.

14. HTML Forms

Forms collect information from users. They are commonly used for registration, login, feedback and contact pages.

<form action="submit.php" method="post">

    <label for="name">Full Name:</label>
    <input type="text" id="name" name="name">

    <label for="email">Email:</label>
    <input type="email" id="email" name="email">

    <button type="submit">Submit</button>

</form>

Form Attributes

  • action: Specifies where form data is sent.
  • method: Specifies how data is sent, commonly GET or POST.
  • name: Identifies a submitted field.
  • required: Makes a field mandatory.
HTML creates the form interface. A server-side language or service is usually needed to process and store submitted data.

21. HTML Audio

The audio element embeds sound files into a web page.

<audio controls>
    <source src="music.mp3" type="audio/mpeg">

</audio>

Audio Attributes

  • controls: Displays playback controls.
  • autoplay: Requests automatic playback, subject to browser policies.
  • loop: Repeats the audio.
  • muted: Starts the audio muted.
  • preload: Gives the browser a loading hint.
Many browsers block autoplay with sound. Provide controls so users can start playback themselves.

29. Web Accessibility

Accessibility means designing websites so people with different abilities can use them.

Accessibility Practices

  • Provide descriptive alt text for meaningful images.
  • Use headings in a logical order.
  • Use labels for form fields.
  • Make interactive controls usable with a keyboard.
  • Use sufficient color contrast.
  • Provide captions for videos where appropriate.
  • Use semantic HTML elements.

31. HTML5 APIs

Modern browsers provide web APIs that JavaScript can use to access browser features and services.

Examples of Web APIs

  • Geolocation API: Can request the user's location.
  • Canvas API: Draws graphics using JavaScript.
  • Web Storage API: Stores information in the browser.
  • Drag and Drop API: Supports dragging and dropping.
  • Web Audio API: Processes and generates audio.
  • Fetch API: Makes network requests.

Local Storage Example

<script>
localStorage.setItem("username", "John");

let name = localStorage.getItem("username");

document.write(name);
</script>
Some APIs require permission or a secure context such as HTTPS. Browser and WebView support may vary.

32. HTML Best Practices

Good coding practices make HTML documents easier to read, maintain and use.

Important Practices

  • Always declare the HTML5 doctype.
  • Use meaningful element names and structure.
  • Write clean and properly indented code.
  • Use lowercase tag and attribute names consistently.
  • Quote attribute values.
  • Provide alt text for meaningful images.
  • Use semantic elements where appropriate.
  • Separate CSS and JavaScript when practical.
  • Test pages on different screen sizes.
  • Validate your HTML code.

Good HTML Example

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
</head>
<body>
    <main>
        <h1>Welcome</h1>
        <p>My first website.</p>
    </main>
</body>
</html>

33. Practical HTML Project

In this project, you will create a simple personal profile website using HTML.

<html lang="en">

    <meta charset="UTF-8">

            font-family: Arial;

            background: white;

            width: 120px;
            height: 120px;

  1. Create an HTML file.
  2. Add your name and profile image.
