# WebCraftStudio

[![Live Website](https://img.shields.io/badge/WebCraftStudio-Visit%20Site-blue?style=for-the-badge)](https://webdeveloper-cpu.github.io/WebCraftStudio/)

WebCraftStudio is a curated collection of modern, responsive web applications crafted with HTML5, CSS3, and JavaScript. From interactive tools to utility platforms, each project showcases clean code, intuitive UI/UX design, and standalone web functionality.

---

## 🚀 Live Applications

* 🌐 **[WebCraftStudio Home](https://webdeveloper-cpu.github.io/WebCraftStudio/)**  
  Explore the full collection of web utilities and interactive applications.

* 🧮 **[OmniCalc Pro Engine](https://webdeveloper-cpu.github.io/WebCraftStudio/ominical_pro.html)**  
  An advanced multi-functional computation engine featuring 17 offline modes including scientific calculation, calculus, matrix algebra, vectors, and graphing capabilities.

* 💱 **[Currency Calculator](https://webdeveloper-cpu.github.io/WebCraftStudio/currency_calculator.html)**  
  A responsive tool to check current exchange rates and compute fast conversions.

* 📁 **[File Converter](https://webdeveloper-cpu.github.io/WebCraftStudio/file_converter.html)**  
  A private, browser-based utility to convert documents, PDFs, and images safely on your device.
